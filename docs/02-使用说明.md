# 02 · 使用说明

> 面向使用者与维护者。代码位置见 `ARCHITECTURE.md`；运行命令以 AGENTS §4 与根目录脚本为准。

## 部署

### 前置条件

- Windows 10 1703+ / Windows 11，x64。
- .NET Framework 4.8（Windows 10/11 通常已内置）。
- 目标软件与 AppTabs 使用相同权限级别；管理员软件需要以管理员身份启动 AppTabs。

### 启动

- 便携目录：双击 `dist\release\unpack\AppTabs.exe`。
- 源码目录：`run.bat`，或直接运行打包后的 exe。
- 单实例：已有 AppTabs 运行时再次启动只会提示，不会打开第二个宿主。

### 加入窗口

点击工具栏“加入窗口”，菜单会平铺最近成功加入的应用；同一应用有多个打开窗口时会打开筛选后的选择器。也可选择“选择窗口…”打开完整选择器，勾选已打开的软件主窗口。自动模式优先尝试嵌入；不满足条件时回退到分组（默认无边框）。软件不会自动接管任何窗口，也不会自动启动软件。

### 分离与关闭

- 标签 ×、中键、Ctrl+W、默认退出：**分离并保留软件**。
- 关闭某个软件：右键标签 →“关闭这个软件窗口…”，只发送窗口关闭请求，不结束整个进程。
- 退出 AppTabs 时若仍有窗口无法还原，程序会继续运行并保留恢复日志，不会强行结束。

## 维护

### 用户数据

| 文件 / 目录 | 内容 |
|---|---|
| `%LOCALAPPDATA%\AppTabs\settings.json` | 宿主位置、挂载偏好、热键候选、托盘、单窗口组 |
| `%LOCALAPPDATA%\AppTabs\library.json` | 命名标签组与应用收藏 |
| `%LOCALAPPDATA%\AppTabs\recovery.json` | 接管中的窗口恢复快照 |
| `%LOCALAPPDATA%\AppTabs\app.log` / `watchdog.log` | 本机诊断日志，约 2 MB 轮转 |

这些文件与 ExplorerTabs 分离；损坏的文件不会被静默覆盖。备份 / 迁移时复制整个 `%LOCALAPPDATA%\AppTabs` 目录即可；重置前先正常退出 AppTabs 并备份。

### 设置

左上角应用图标 →“设置…”：

- **常规**：默认挂载模式、最近加入应用数量（1–20）、分组窗口无边框开关。挂载模式与无边框设置只影响之后加入的窗口；关闭无边框可回退软件原生标题栏 / 边框。
- **快捷键**：选择 / 停用全局呼出组合；勾选“切后台时隐藏到系统托盘”，托盘图标只在隐藏期间出现；查看固定标签快捷键。

### 标签组与收藏

- 窗口组的书签菜单可保存 / 恢复单窗口组，也可“保存为标签组…”保存多套命名快照。
- 标签组恢复只匹配已经打开、映像 / 类名 / 标题一致的唯一窗口，并追加到当前标签；不会启动软件。
- “收藏应用…”只接受本地 `.exe`；点击收藏直接启动，不自动挂载。管理页可改名、更换程序、删除收藏 / 标签组。
- 同名标签组覆盖需要确认；保存失败时管理页保留编辑供重试。

### 构建与发布

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

或双击 `build.bat`。其他入口：`test.bat`（测试）、`dev.bat -BuildOnly`（隔离 Debug 构建，不启动）、`package.bat`（dev + release 打包）、`clean.bat`（清理构建产物，保留 `dist\`）。

发布包布局：

```text
dist\dev\AppTabs_<版本>_x64-unpack-debug.zip
dist\release\unpack\
dist\release\AppTabs_<版本>_x64-unpack.zip
dist\release\SHA256SUMS.txt
```

打包时如果 AppTabs 正从 `dist\release\unpack` 运行，脚本会列出进程并取消，**不会结束进程**；请正常退出后重试。

## 调试

### 启动失败

查看 `%LOCALAPPDATA%\AppTabs\app.log` 与 `watchdog.log`。启动异常会写入诊断并返回失败码；单实例冲突、恢复日志 owner 未退出、恢复失败都会阻止启动。

### 恢复日志

异常退出后，下次启动会尝试还原仍存活的窗口。若日志对应的宿主仍在运行，AppTabs 会拒绝接管；不要把查询失败当成窗口消失。恢复失败时保留日志与软件状态，按提示处理后再重试。

### 第三方软件异常

- 焦点 / 输入 / 弹窗异常：先尝试切换为分组；若与软件自绘边框冲突，可在设置中关闭“分组窗口使用无边框”。
- 目标窗口有未处理模态框、置顶或未响应：先处理软件自身状态，再重新加入。
- DPI awareness 不一致：自动模式会回退到分组；不要修改目标进程的 DPI 设置。
- 任务栏 / 多显示器异常：记录软件名、窗口标题、模式与实际表现，便于后续兼容性迭代。

### 测试限制

自动测试只使用 fake 接口、自建离屏窗口与独立临时配置；不注册真实全局热键 / 键盘钩子，不枚举或操作用户已有软件。真实拖动、贴边、跨屏 DPI、托盘、快捷键和第三方软件行为必须由用户实测。

### 文档体检

```bash
sh check-docs.sh
```

检查占位符、根文档与 `CLAUDE.md`、文档体量、脚本换行与 CHANGELOG 疑似漏记；有 FAIL 时退出码为 1。
